# khandanian — Developer Portfolio

A Persian-first, RTL, responsive developer portfolio with a dark UI and GitHub Pages deployment.

## Features
- Responsive desktop/mobile layout
- Persian RTL interface and semantic HTML
- Project cards defined in `assets/app.js`
- GitHub Actions deployment to GitHub Pages
- No build dependencies or API keys

## Preview locally
Open `index.html` in your browser, or run `python -m http.server 8080`.

## GitHub Pages
In repository **Settings → Pages**, choose **GitHub Actions** under Build and deployment / Source. Then monitor the **Actions** tab.

Expected public URL after successful deployment:
https://khandanian.github.io/developer-portfolio/

## Customize
- Content: `index.html`
- Projects: `assets/app.js`
- Styling: `assets/style.css`

The two upcoming projects are labeled as such; they are not presented as completed work.
